PROJECT BUNU — PRIME CREATIONS
================================

Files:
- index.html: the complete website
- style.css: visual design and responsive layout
- script.js: countdown, photo lightbox, gift reveal and music toggle
- assets/prime-creations-logo.png: your supplied Prime Creations logo
- assets/photos/: the 10 supplied photographs

Preview:
Open index.html in a browser.

Publish with GitHub Pages:
1. Extract this ZIP.
2. Create/open your GitHub repository.
3. Upload the CONTENTS of this project-bunu folder (index.html, style.css, script.js, assets).
4. Keep index.html at the repository root.
5. In Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
6. Wait for GitHub Pages to publish.

Notes:
- Countdown targets 28 November 2026, India Standard Time.
- The gift button is interactive and can be opened any time; the countdown marks the date.
- Background music is optional and starts only after the visitor taps the music button. It uses an online audio file, so internet is required for that track.
- Contact details are displayed exactly as provided.
- Replace the generic letter text with personal memories if you want a more specific message.
